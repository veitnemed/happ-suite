# ЭТАП 04 — глобальная клавиша F8, единая машина состояний, трей

Реализуй на Windows единую очередь событий для UI и сетевых действий. Горячая клавиша по умолчанию F8, может переназначаться. Предпочти Win32 `RegisterHotKey` с корректным message loop; учти взаимодействие с pystray/его event loop.

Контракт:
- OFF + F8 => STARTING (HAPP + AG Unlocker, безопасный порядок определяется результатом аудита) => READY только после проверок;
- READY + F8 => STOPPING => OFF;
- STARTING + F8 => отменить незавершённый переход и вернуть известное состояние;
- ERROR + F8 => контролируемая повторная попытка, без дубликатов;
- многократные нажатия не запускают параллельные сценарии; ошибки освобождают mutex/lock.

В трее серый OFF, жёлтый CONNECTING/STOPPING/RECOVERING, зелёный READY, красный ERROR. При DEGRADED отображай отдельное состояние/tooltip, не маскируй как зелёный. Информация по HAPP и AG Unlocker раздельно, но единая кнопка Connect/Disconnect. Поддержать безопасный выход и восстановление иконки при перезапуске Explorer.

Проверить реальную регистрацию и конфликт клавиши (честное сообщение + выбор другого сочетания); не перехватывай клавиши низкоуровневыми hook без нужды. UI не блокируется синхронными ping, sleep и subprocess. Никаких всплывающих консолей. Подтверждённый background startup без автоподключения, если пользователь не включил эту настройку.

Тесты: state machine, F8 spam, STARTING→cancel, отказ регистрации, пустой GUI, двойной экземпляр приложения, восстановление Explorer. Для реального переключения сначала этап 07/разрешение пользователя.
