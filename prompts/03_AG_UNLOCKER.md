# ЭТАП 03 — AG Unlocker, без навязчивых окон

У пользователя AG Unlocker запускается из отдельного `AG Unlocker.exe`. Он уже установлен; Happ Suite должен включать его при F8 автоматически.

1. Найди подтверждённый путь к `AG Unlocker.exe` конфигом или безопасным discovery. Проверь подпись/путь по возможности, не загружай сторонний EXE «на глаз».
2. Изучи фактические дочерние процессы, службы, DNS-изменения и корректный штатный способ выключения. Не считай `ag_dns.exe` универсальной гарантией работоспособности и не убивай чужие службы.
3. Изучи, поддерживает ли версия AG Unlocker minimized/background/командную строку. Без подтверждения не добавляй вымышленные аргументы и не обещай «вообще ни одного кадра окна».
4. Сделай `AGUnlockerAdapter` со статусом `NOT_INSTALLED/OFF/STARTING/READY/DEGRADED/ERROR`, тайм-аутом, безопасным стартом и ownership. Если уже запущен пользователем — подключи мониторинг без перезапуска и не останавливай его по F8.
5. Реальная проверка готовности: статус необходимых локальных компонентов и прикладная проверка доступности нужного пути Antigravity (не только наличие процесса); не выводить ложное «READY» из одного HTTP 200 страницы логина.
6. При выключении F8 возвращай только настройки, реально изменённые Suite; не выключай AG Unlocker, если он принадлежал пользователю до запуска.

Unit/mock тесты: запуск отсутствующего EXE, существующий пользовательский процесс, неожиданный exit, медленный старт, отсутствие готовности при запущенном процессе, отмена, повторный start/stop. Проверка с установленным EXE — только с разрешением на изменение локальной системы; если нет Windows окружения — BLOCKED.
