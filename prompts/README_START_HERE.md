# Happ Suite — цикл заданий для Codex

Цель: довести https://github.com/veitnemed/happ-suite до проверяемого MVP: **одна глобальная клавиша F8 включает/выключает HAPP VPN и установленный AG Unlocker; приложения работают без навязчивых окон, а в трее показывается достоверный статус**.

## Как использовать

1. Распакуйте архив в корень локального репозитория: получится папка `prompts/` (либо передайте Codex путь к распакованной папке).
2. Откройте репозиторий в Codex. Вставьте содержание `00_MASTER_LOOP.md` одним сообщением. Попросите читать остальные промпты **по порядку**.
3. Разрешите обычное редактирование файлов и безопасные локальные тесты. **Для первого реального отключения VPN, изменения системных маршрутов, DNS, служб, прав администратора и запуска установщика от администратора потребуется отдельное подтверждение.**
4. При потере соединения отправьте Codex: «Продолжи по prompts/00_MASTER_LOOP.md и последнему checkpoint в prompts_progress/STATUS.md».
5. Каждый этап должен закончиться изменениями в репозитории, проверками и зафиксированным результатом, а не словами «готово».

Порядок файлов:

- `00_MASTER_LOOP.md` — главный управляющий промпт «делай → тестируй → исправляй → повторяй».
- `01_AUDIT.md` — инвентаризация существующего Happ Suite и установленного ПО.
- `02_HAPP_BACKGROUND.md` — тихое управление штатным HAPP.
- `03_AG_UNLOCKER.md` — запуск и проверка AG Unlocker.
- `04_F8_TRAY_STATE.md` — одна клавиша и индикатор.
- `05_SUBSCRIPTIONS_SERVERS.md` — универсальность и выбор серверов.
- `06_HEALTH_RECOVERY.md` — достоверные проверки, устойчивость, безопасное отключение.
- `07_OFFLINE_SWITCH_BRIDGE.md` — **отдельный** независимый исполнитель для сетевых экспериментов.
- `08_PACKAGING_TESTS.md` — сборка, документация, тесты, итоговая проверка.
- `09_ACCEPTANCE_MATRIX.md` — критерии, которые нельзя подменять обещаниями.

Архив содержит промпты, не готовое приложение. Цикл не может гарантировать обход всех внешних ограничений (особенности HAPP, AG Unlocker, права Windows, недоступный сервер, сетевые блокировки). Если реальное тестирование требует пользователя/администратора, Codex фиксирует блокирующее условие и даёт **одну точную инструкцию**, а не изображает успех.
