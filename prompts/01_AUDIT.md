# ЭТАП 01 — аудит кода и окружения

Исследуй текущий репозиторий, в частности `src/core.py`, `src/config.py`, `src/server_picker.py`, `src/health.py`, `src/tray.py`, `src/main.py`, `run.bat`, `scripts/build.py`, `config/default.json`, `pyproject.toml`.

Проверь фактами (не доверяй описанию README):
- HAPP сейчас запускается `Happ.exe --autostart`, затем окно скрывается `ShowWindow`. Есть ли документированная возможность background/minimized? Не выдумывай CLI-ключи.
- `HappVPNComponent.is_running()` и health смотрят прежде всего на открытый локальный порт, а не системный туннель.
- `_kill_happ()` и Zapret stop могут завершать ВСЕ процессы по имени; введи ownership и безопасный путь остановки.
- `AGUnlockerComponent.start()` сейчас, вероятно, лишь проверяет наличие `ag_dns.exe`, не запускает приложение.
- Список серверов в `config/default.json` может содержать фиксированные IP/ID конкретного пользователя; это не универсальная подписка.
- `tray.py` может иметь лишь start/stop-меню и не регистрировать глобальную F8; OFF рисуется красным вместо серого.
- `run.bat` требует Python, хотя README может обещать готовый EXE.

Установленное ПО на Windows: найди HAPP, AG Unlocker и их связанные процессы, ПОСЛЕ разрешённых диагностических операций. Установи безопасный путь к EXE, пользовательские настройки, поведение при ручном запуске/выходе, права. Если нет доступа к пользовательскому Windows, запиши BLOCKED и реализуй абстракции + моки. Не ищи/не публикуй секреты подписок.

Результат: `prompts_progress/AUDIT.md` с таблицей «функция / файл / фактическое состояние / ограничение / эксперимент» и планом минимальных изменений. Запусти baseline tests, если существуют; отсутствие тестов тоже зафиксируй. Не трогай сеть.
