# Relay Studio

Приложение для Windows с тёмным интерфейсом Qt Widgets (PySide6): **VPN / Серверы**, **Gemini Web**, **Antigravity**, **Настройки**. VPN работает через Mihomo. Gemini Web управляет DNS текущей сети, а Antigravity запускает локальный relay. Каждый режим включается отдельно.

## Запуск исходного кода

1. В папке проекта выполните `py -3 -m pip install -e .` (только при первой установке зависимостей).
2. Запустите `py -3 start.py`. Для запуска без консоли используйте `pyw -3 start.pyw`.
3. При необходимости подготовьте Mihomo без запуска VPN командой `py -3 start.py --bootstrap-mihomo`.
4. Откройте **Настройки** и установите Mihomo и компонент Antigravity, если их ещё нет.
5. На странице **VPN / Серверы** вставьте HTTPS-ссылку подписки и нажмите **Сохранить**. Серверы появятся в списке с поиском. Выделите сервер и нажмите **Применить сервер**, затем **Подключить**. Ссылка сохраняется локально с защитой DPAPI.

Закрытие окна сворачивает приложение в трей. Повторный запуск `start.py` показывает уже работающий экземпляр. `run.bat` использует `.venv`, если она существует. Тема только тёмная; масштабирование выполняет Qt без дополнительного увеличения размеров.

Для просмотра интерфейса без сети, трея и глобальных клавиш: `python -m src.ui_qt.preview` или `python start.py --ui-preview`. Дополнительные сценарии: `--scenario empty`, `--scenario error`, `--scenario loading`; страницы: `--page google`, `--page ag`, `--page settings`. Тесты: `python -m pytest -q`. Условия распространения Qt перечислены в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Режимы

- **VPN:** отдельное включение и выключение Mihomo. Выделение строки не меняет маршрут; команда **Применить сервер** переключает узел либо сохраняет его для следующего подключения. **Лучший зарубежный** подключает зарубежный узел при выключенном VPN, сравнивает доступные узлы по задержке и проверяет страну фактического выхода. Во время проверки маршрут переключается. Узлы без указанной страны и российские узлы в автоматический выбор не попадают. Если подтвердить зарубежный выход не удалось, восстанавливается узел, активный перед сравнением.
- **Gemini Web:** включает и возвращает DNS текущего Wi-Fi или Ethernet. Кнопки проверки сайта и открытия Gemini находятся в этом разделе. Доступность сайта сама по себе не подтверждает доступ к модели в аккаунте.
- **Antigravity:** включает и выключает локальный relay независимо от VPN и DNS.

Если в Windows уже активен другой VPN-туннель, Mihomo не запускает второй. Отключите внешний VPN вручную, прежде чем включать Mihomo.

## Горячие клавиши и автозапуск

По умолчанию: `Ctrl+Alt+H` — VPN, `Ctrl+Alt+D` — Gemini Web DNS, `Ctrl+Alt+G` — Antigravity. В **Настройках** можно выбрать F8/F10/F9, другие предложенные сочетания или записать свою клавишу. Там же включается запуск вместе с Windows и открывается локальный журнал.

Данные прежней установки пока хранятся в `%LOCALAPPDATA%\HappSuite`: это сохраняет подписку, настройки и привязку уже работающего Mihomo после обновления исходного кода. Ссылка подписки не выводится в журнал.

Сначала проверяйте изменения через `start.py`. Переключение VPN и DNS на рабочем компьютере выполняйте вручную; сборку EXE делайте после проверки интерфейса и режимов.

## Сборка Windows Setup

Setup собирается из чистого PyInstaller onedir-каталога и не включает пользовательскую папку `%LOCALAPPDATA%\HappSuite`:

```powershell
py -3 -m pip install -e ".[test]" pyinstaller
py -3 scripts/build.py --entry start --dist-dir dist\app --work-dir build\app
py -3 scripts/build_setup.py --source dist\app\RelayStudio
```

Для последнего шага нужен Inno Setup 6. Установщик ставит приложение в пользовательскую папку Programs, создаёт ярлыки и запись удаления. После установки он проверяет/устанавливает Mihomo; без интернета Relay Studio остаётся установленным, а в мастере показывается, как повторить установку Mihomo позже.
